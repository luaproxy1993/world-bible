# Changelog

## 1.8.0

Public skill release.

- **Voice:** production manual. Complete sentences that chain facts. No fragment stacks, no diary, no interior thought. Local names glossed in the same sentence.
- **Vignette:** a brief (what it is, who uses it, one dated proof of a Law). Not a short story.
- **Look:** `lock.look` judged from intake at W0 (`oil-box` `glossy-photo` `cinematic-still` `cel` `print`). W5 look-dev only when `source` is `inferred`. One canonical style-anchor.
- **Compile:** `overview.html` falls back to `lock.json` when world JSON is still empty, so a lock-only bible still has a team overview.
